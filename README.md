# Greg Tomco Portfolio

A modern personal portfolio website for Greg Tomco, showcasing his background in Information Technology, network technology, security, automation, and full-stack development. The site is built as a single-page responsive portfolio with a sleek dark design, smooth scrolling, animated sections, and strong branding for professional networking and opportunities.

## Overview

This project presents Greg's:

- IT and networking background
- education and certifications
- skills and technical capabilities
- work experience and internship highlights
- featured project work
- contact details for hiring or collaboration

The site is designed to feel polished and professional while remaining lightweight and easy to host on any static web server.

## Features

- Responsive single-page portfolio layout
- Dark, modern UI with gradient accents
- Animated reveal effects and smooth scrolling
- Typewriter-style hero text
- Skills, experience, and certifications sections
- Featured project highlight
- Contact cards and direct email/phone links
- Downloadable résumé button (if the résumé file is included)
- Bootstrap-based styling with custom CSS enhancements

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

## Running the Project Locally

Since this is a static website, you can run it in a few simple ways:

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Serve locally with Python

```bash
cd c:/xampp/htdocs/portfolio
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

### Option 3: Use XAMPP

Place the project folder inside `htdocs` and open it through your local Apache server.

## Customizing the Portfolio

You can personalize the site by editing the content in `index.html`:

- update the name and title text
- replace the role text in the typed-effect script
- modify the about, skills, and experience sections
- update contact email, phone number, and location
- add or remove certifications and project details
- change colors and branding in the CSS variables and design tokens near the top of the document
