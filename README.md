# Greg Tomco Portfolio

A modern personal portfolio website for Greg Tomco, showcasing his background in Information Technology, network technology, security, automation, and software development.

This project is built as a responsive single-page portfolio using HTML, CSS, Bootstrap, and JavaScript. It highlights the user's education, experience, technical skills, certifications, featured project, and contact details in a clean dark-themed interface.

## Live Preview

Open the site locally in a browser by launching the project folder or serving it through a small local web server.

## Features

- Responsive single-page portfolio layout
- Modern dark gradient UI with animated sections
- Typed headline effect and scroll reveal animations
- Skills, education, and experience sections
- Featured project highlight
- Certifications and contact information
- Resume download button support
- Mobile-friendly navigation

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Google Fonts
- Bootstrap Icons

## How to Run

Because this is a static website, there is no package installation required.

### Option 1: Open directly

- Open `index.html` in your browser.

### Option 2: Run a local web server

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customization

To personalize the portfolio for your own use, update the following in `index.html`:

- Name and title text
- Email address and phone number
- Location details
- Skills and certifications
- Education and experience entries
- Featured project information
- Social/contact links

If you want the resume download button to work, place your PDF in the project root and keep the filename matching the link in the page.

## Notes

This portfolio is designed to be easy to edit and deploy. The page uses CDN-hosted libraries for Bootstrap and icons, so no local dependency installation is required.
